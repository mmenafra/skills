# Rewrite it

Rewrite what the user points at, or your last reply when they name nothing.
Keep its meaning, facts, and any exact quoted text such as code, commands, or
logs, and return only the rewrite.

- Open with the point: the answer, result, or ask, in one short paragraph the
  reader can act on without reading further.
- Write so the reader can follow it cold. Call things by names they'd know,
  and define any label the thread coined.
- Keep it simpler and shorter than feels necessary. Cut filler, hedges,
  restated points, and anything the reader doesn't need to act or trust it.
- Use plain words and short sentences. Prefer active voice and concrete
  claims over abstractions.
- Use lists only for steps or parallel items; otherwise write short
  paragraphs.
- Match the tone and format the user asked for, which wins over these rules.
